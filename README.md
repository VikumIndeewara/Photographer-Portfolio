# 📸 Photographer Portfolio Website

A sleek and modern photographer portfolio website built using **React**, **Vite**, and **Tailwind CSS**. This frontend-only project showcases a professional image gallery, smooth animations via **GSAP**, and a session booking feature through email. The website is fully responsive and deployed live via **Vercel**.

## 🧩 Features

- ✨ **Animated UI** using [GSAP](https://greensock.com/gsap/)
- 🖼️ **Gallery section** with sample photographs
- 🏠 **Home Page** with 5 curated sections
  - Hero section
  - About/Introduction
  - Services or Portfolio
  - Gallery
  - Contact/Call to Action
- 📩 **Book a Session** page: prefilled email link for easy session booking
- 📱 **Responsive Design**: Mobile-first layout for all screen sizes
- ⚡ **Fast & Lightweight** build using Vite

---

## 🚀 Tech Stack

- **React** – JavaScript library for building user interfaces
- **Vite** – Lightning-fast development and build tool
- **Tailwind CSS** – Utility-first CSS framework
- **GSAP** – JavaScript animation library
- **Vercel** – Hosting and deployment platform
